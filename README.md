# live-assistant-scheduler

为银行螺丝钉直播间的小助手续排每月值班表，并写入飞书表格的 Codex Skill。

这里的“小助手”是直播间聊天区的人工答疑人员，不是 AI 助手。

> 本 README 是给同事看的快速导览；AI 执行时以 [`SKILL.md`](SKILL.md) 为准。

## 能做什么

- 生成指定月份中非法定节假日的每周二、周五直播场次。
- 从排期表最后一场继续轮转，不重新从头排，也不按历史次数配平。
- 为每场安排 2 位资深小助手和 1 位初级小助手。
- 按表格的列优先布局写入飞书电子表格。
- 写入前检查目标区域，写入后回读核验并展示最终排期。

## 什么时候使用

同事提出以下需求时使用：

- “把直播小助手排期表续排到下个月。”
- “安排 2026 年 10 月直播小助手值班。”
- “按上个月最后一场接着排，并跳过法定节假日。”
- “检查这份小助手排期有没有接错轮次。”

## 需要提供什么

- 要续排的年份和月份。
- 直播小助手排期表的访问和编辑权限。
- 如果人员或排班规则有临时变化，需要提前说明；否则以表格当前人员映射和 `SKILL.md` 的固定轮转规则为准。

## 会产出什么

- 指定月份的直播日期和小助手组合清单。
- 写入飞书表格后的正式排期。
- 被排除的法定节假日说明。
- 本次续排承接的上一场组合和回读核验结果。

## 核心排班规则

- 场次安排在非法定节假日的每周二、周五。
- 资深组合固定循环：`6+9 → 5+8 → 5+9 → 6+8`。
- 初级小助手 `3` 和 `7` 交替轮转。
- 每场固定写成“资深1、资深2、初级”，例如 `6、9、7`。
- 新月份必须承接表格中上一场的实际组合。

人员可能变化，编号与姓名的对应关系最终以飞书排期表为准。

## 工作流程

1. 查询当年法定节假日并生成该月有效直播日期。
2. 读取排期表，定位最后一场的资深组合和初级人选。
3. 按固定循环生成新月份每一场安排。
4. 按 `B/C → D/E → F/G` 的列优先方式映射到单元格。
5. 确认目标区域为空后写入，并回读核验。

## 安装

```bash
git clone https://github.com/fanlili321/live-assistant-scheduler-skill.git \
  ~/.codex/skills/live-assistant-scheduler
```

安装后可这样触发：

```text
使用 $live-assistant-scheduler，把直播小助手排期表续排到 2026 年 10 月。
```

## 依赖与权限

- Codex Skills 运行环境。
- 飞书排期表的读取和编辑权限。
- 可用的飞书电子表格操作能力。
- 能查询国务院公布的当年法定节假日安排。

## 使用边界

- 不负责直播文字稿整理、直播大纲或 Keynote 制作。
- 不使用“历史出场次数配平”等其他排班算法。
- 不猜测上一场组合；必须从飞书表格读取真实数据。
- 不在未确认目标区域为空时直接写入。

详细人员映射、单元格结构、写入步骤和示例见 [`SKILL.md`](SKILL.md)。
